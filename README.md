# 小学家长教育推广渠道调研

面向中国**小学生家长（孩子 6–12 岁）**的在线教育推广渠道调研报告。逐一拆解小红书、微信生态、抖音，以及快手、知乎、百度、电商、亲子音频、AI 助手等渠道的：

- 家长触达能力与人群结构；
- 有效内容形式（测评 / 打卡 / 避坑 / 清单 / 名师人设 / 资料钩子）；
- 转化链路与获客成本区间；
- 按产品类型（教育硬件 / 在线素质课 / 本地教培 / 家长课 / 图书）给出的渠道组合建议；
- 双减后的合规红线。

## 结论速览

> **不是三选一，而是分工：小红书 / 抖音负责种草和触发咨询，微信（企业微信私域）负责成交和续费。**
>
> - **小红书**：决策种草主阵地，适合中高客单素质课与教育硬件；线索约 80–300 元（推断）。
> - **微信**：私域成交与续费底座，视频号直播 + 企微体验课群为核心；体验课转正价约 10%–25%。
> - **抖音**：规模流量与硬件直播主战场，本地教培团购在寒暑假有四个月窗口期。
> - **学科提分课**：各主流平台公开投放与直播均为合规红线。

## 数据口径声明

报告基于 2024–2026 年公开资料的桌面调研（约 65 组关键词检索）。文内数字按三级标注：

- **公开数据**：官方统计、财报、平台公告；
- **行业估算**：第三方研究机构与媒体口径；
- **推断**：基于上述材料的分析判断。

成本与转化率多为行业估算区间，不构成投放承诺；正式投放前请以小预算实测并核验最新平台规则与广告法规。主要来源与数据缺口在报告文末列出。
